1 · The problem 0:00–1:00 · Darshan

Say
"Show of hands: who has pasted something personal into ChatGPT? A bank letter, a resume, a screenshot of an error?
Millions of Indians now use ChatGPT for bank letters, KYC emails and job applications, and they paste their Aadhaar, PAN and phone number straight in. Developers paste logs and code with API keys and passwords. In 2023, Samsung engineers leaked internal source code this way, and Samsung had to ban these tools.
Once you press Send, that data is on someone else's server. You can't take it back. And India's new Digital Personal Data Protection Act, 2023 makes protecting personal data a legal duty. People need AI, but they need it safely."
Show: title slide. How: pause after the question; let them think. Serious tone.

2 · What MIRAGE is 1:00–2:00 · Darshan

"MIRAGE is a privacy firewall for AI. It sits between you and the AI and checks every prompt before it is sent, on your own device.
Personal details like Aadhaar and PAN become placeholders, so the AI can still answer. Secrets like API keys and passwords are removed completely. And when the answer comes back, MIRAGE puts your real details back, only on your screen.
Most tools just block you. MIRAGE lets you keep using AI and keeps your data out of it. We built it three ways, because people use AI in three places: the browser, the ChatGPT and Claude desktop apps, and the terminal."
Show: the flow slide: "Aadhaar · PAN · API key → MIRAGE (on your device) → «AADHAAR_1» «PAN_1» «API_KEY_REMOVED» → AI".

6 · How it works and what's new 8:30–9:30 · [Name]

"Under the hood, it's one detection engine written in TypeScript, and the same engine runs in all three products.
It doesn't just match patterns. It verifies them: Aadhaar with the Verhoeff checksum, card numbers with Luhn, PAN with its format rules, so random numbers don't cause false alarms. It measures entropy to spot random-looking API keys, and it reads context: words like 'DOB' or 'my name is'. It even catches tricks like 'gmail [dot] com' or hidden characters.
Then it gives a risk score from 0 to 100 and explains every point. On our test set of 181 prompts, precision is 1.0 and recall 0.996, in 0.05 milliseconds per prompt. We wrote that test set ourselves, so an independent test is our next step.
What's new: India-first detection with real checksums, reversible placeholders so the AI still answers, and interception inside native desktop apps, not just websites. And there's no server: real values are encrypted on your device and deleted after 24 hours."
Show: the tech stack slide: one engine → Extension (WXT + React) · Desktop (Swift / .NET) · CLI (Node.js).

Q&A · short, honest answers Anyone

If they askSay
Does data go to your server?"No. There's no MIRAGE server. Detection runs on the device; only the protected prompt goes to the AI."
Why not use an AI model to detect?"Speed and privacy: rules with checksums run in 0.05 ms, offline, and every result is explainable. A model would need a server or a big download."
What does it miss?"Names only with context like 'my name is'; a PAN split with spaces; non-English text. That's why the review shows exactly what will be hidden, so the user stays in control."
Isn't the desktop app a keylogger?"No. It only reads ChatGPT's and Claude's message box while they're open, only reacts to Enter and the Send button, never records the screen and never logs text."
How is it different from existing tools?"Enterprise tools block and report to admins. MIRAGE is for individuals: it hides details so the AI still works, restores them in the reply, and understands Indian IDs with real checksums."
Business model / next steps?"Free for individuals. Next: a blind accuracy test, the Chrome Web Store, testing the Windows app with ChatGPT, and a team version for companies under the DPDP Act."
Is Windows ready?"It's a beta: built and tested automatically on Windows, but we haven't tried it with the ChatGPT app on Windows yet."

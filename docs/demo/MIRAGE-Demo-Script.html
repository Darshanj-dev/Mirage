MIRAGE · Demo Script

A privacy firewall for AI: personal details become placeholders and secrets never leave the device, before the prompt is sent.

Team Nexora Date 30 September 2026 Length about 10 minutes + Q&A Parts Browser extension · Desktop companion · CLI
All data in this script is made up. Never type real details on stage. Every input below was run through MIRAGE's detector on 29 Sep 2026, and the scores and outputs shown are what it produced.

Before you present (15 minutes earlier)

Browser (Chrome)

  • MIRAGE extension loaded and pinned (shield in the toolbar shows Protection on).
  • chatgpt.com logged in, new chat open.
  • Turn off other extensions (Grammarly etc.).
  • Zoom the page to 125% so the room can read it.

Desktop (Mac)

  • MIRAGE running: shield in the menu bar, status Protected for ChatGPT.
  • ChatGPT desktop app open on a new chat; the "MIRAGE active" badge shows above the message box.
  • Menu bar → MIRAGE: Show "MIRAGE active" is on.
  • If the badge doesn't show: System Settings → Privacy & Security → Accessibility → MIRAGE on, then relaunch MIRAGE.

CLI (terminal)

  • Installed: npm install -g https://github.com/NinadPandith/Mirage-Cli/raw/main/release/nexora-mirage-cli-0.1.8.tgz
  • Reset so the demo map is the latest: mirage maps clear --yes
  • Practice files: mirage demo then cd mirage-demo
  • Terminal font 20 pt or more.
  • For the chat step: claude -p "say hi" answers (Claude Code logged in).

General

  • Phone hotspot ready in case the Wi-Fi is bad.
  • This PDF open on a second screen, or the inputs (page 6) in a notes app to copy from.
  • Notifications off (Do Not Disturb).

Opening · 0:00–0:45

"Every day people paste their PAN, Aadhaar, phone numbers and even API keys into ChatGPT and Claude. Once it's sent, it's on someone else's server. MIRAGE is a privacy firewall for AI: it checks every prompt on your own device, replaces personal details with placeholders, removes secrets completely, and nothing is sent until you choose. The same engine runs in three places: the browser, the ChatGPT and Claude desktop apps, and the terminal."

Part A · Browser extension on chatgpt.com · 0:45–4:00

A1 · A normal prompt passes untouched (20 s)

Type in ChatGPT
Explain how UPI payments work in three simple lines.
What happens

No popup. The message sends as usual. Safe · 0/100

Say

"No false alarms: if there's nothing sensitive, MIRAGE stays out of the way."

A2 · Personal details get hidden (60 s) ★ main moment

Type (or paste) in ChatGPT, then press Enter
Hi, I'm Priya Nair. My PAN is BNZPM2501K, Aadhaar 2341 2341 2346, phone 98450 12345 and email priya.nair@gmail.com. Write a short letter to my bank asking them to update my KYC.
What happens
  • While typing, the shield badge by the message box turns red.
  • Enter is stopped and the review opens: 5 items will be hidden before sending · Critical · 100/100 · Name, PAN, Aadhaar, Phone, Email.
  • Click Review to show "Why 100?", the points behind the score.
  • Click Protect & send. ChatGPT receives:
Hi, I'm «PERSON_1». My PAN is «PAN_1», Aadhaar «AADHAAR_1», phone «PHONE_1» and email «EMAIL_1». Write a short letter to my bank asking them to update my KYC.
  • In ChatGPT's reply, hover a placeholder: MIRAGE shows the real value, on this laptop only. Use Copy with details under the reply to copy the letter with the real details filled in.
Say

"ChatGPT never saw Priya's PAN or Aadhaar, only placeholders. The real values stay encrypted on this laptop and come back in the reply only here. The Aadhaar is confirmed with its checksum, so random 12-digit numbers don't trigger it."

A3 · Secrets are blocked, not hidden (40 s)

Type, then press Enter
My deploy keeps failing. Config: AWS_ACCESS_KEY_ID=AKIAQ7Z3MIRAGEDEMO42 and db password=S3cr3tPass@2026. What is wrong?
What happens

Critical · 100/100 · AWS access key + password. Protect & send sends:

My deploy keeps failing. Config: AWS_ACCESS_KEY_ID=«AWS_ACCESS_KEY_REMOVED» and db password=«PASSWORD_REMOVED». What is wrong?

Point out: Send anyway asks for a second confirmation for secrets.

Say

"Keys and passwords are never stored and never put back. They're simply removed. One leaked AWS key can cost lakhs."

A4 · Health data: keep what the AI needs (30 s)

My name is Arjun Menon, DOB 14/03/2002. My HbA1c is 7.9 and I take metformin. What diet should I follow?

High · 52/100 · the name and DOB are hidden; HbA1c 7.9 and metformin are kept (the AI needs them) but counted in the score, with +15 for health data tied to a person.

My name is «PERSON_1», DOB «DOB_1». My HbA1c is 7.9 and I take metformin. What diet should I follow?

"It's not a blind filter: the medical detail stays so the answer is still useful, but the AI can't tell whose it is."

A5 · Tricks don't work (20 s, optional)

Why was my payment declined? Card 4111 1111 1111 1111, expiry 12/28, OTP 482913.

Critical · 99/100 → Card «CARD_REMOVED», OTP «OTP_REMOVED» (the card is confirmed with the Luhn check).

Email me at priya.nair [at] gmail [dot] com and call +91-98450-12345.

The disguised email and the dashed phone number are both caught: «EMAIL_1», «PHONE_1».

A6 · Private Compose: the strongest mode (40 s)

  1. Click the MIRAGE shield in the toolbar → Private Compose. A side panel opens.
  2. Paste the A2 prompt into the side panel. It shows 5 items will be hidden or removed and a live preview with the placeholders.
  3. Click Insert protected. Only the protected text lands in ChatGPT's box → press Send.

"Here ChatGPT's page never sees the raw text at all, not even while you type."

Part B · Desktop companion in the ChatGPT Mac app · 4:00–7:00

"Many people don't use the website at all; they use the ChatGPT and Claude desktop apps. A browser extension can't see those, so we built a desktop companion that works the same way."

B1 · It's on (15 s)

Point at the shield in the menu bar (status: ChatGPT Protected) and the green "MIRAGE active" badge above ChatGPT's message box.

"This badge tells you MIRAGE is watching this box. It only reads the message box of ChatGPT and Claude: no keylogger, no screen recording."

B2 · The review opens as you type (60 s) ★ main moment

Type in the ChatGPT app (don't press Enter yet)
I'm Rahul Sharma. My PAN is PQRSX6789K and my UPI is rahul.sharma@okhdfcbank. Draft an email to HDFC support, IFSC HDFC0001234, asking why my refund is late.
What happens
  • The badge turns amber: 4 items will be hidden.
  • About 0.15 s after you stop typing, the review opens above the box: High privacy risk · 55/100 · "Your information has NOT been sent yet." · Name, PAN, UPI, IFSC.
  • Press Enter to show that nothing is sent while the review is open.
  • Click Protect & Send. MIRAGE rewrites the box, sends it and shows "Sent protected · 4 hidden · 0 removed". The chat shows:
I'm «PERSON_1». My PAN is «PAN_1» and my UPI is «UPI_1». Draft an email to HDFC support, IFSC «IFSC_1», asking why my refund is late.

"Exactly like the extension, but inside a native app. The message is held until you decide."

B3 · A secret in code (40 s)

Fix this code: const key = "sk-proj-Xy7Qm2Lp9Rt4Vb8Nc3Kd6Hf1Js5Gw0Ez"; fetch(url, { headers: { Authorization: key } })

The badge shows Secret · won't be sent; the review says Critical privacy risk · 71/100. Protect & Send sends:

Fix this code: const key = "«OPENAI_KEY_REMOVED»"; fetch(url, { headers: { Authorization: key } })

B4 · Cancel leaves everything untouched (20 s)

Type the A2 prompt, and when the review opens click Cancel. The text stays in the box exactly as typed, and nothing was sent.

B5 · Private Compose on the desktop (30 s, optional)

Press ⌥⌘M (or menu bar → Private Compose). Type the B2 prompt in MIRAGE's own window, check the preview, choose ChatGPT, then click Insert protected. Only the protected text goes into ChatGPT.

Windows: the same companion is available for Windows as a beta. Install it with Install-MIRAGE-Desktop.bat from github.com/Darshanj-dev/Mirage#download. It is built and self-tested on Windows by GitHub Actions but not yet tried with the ChatGPT or Claude apps on Windows, so say "beta" if asked.

"One detection engine and three products: the browser, the desktop apps and the terminal. Everything runs on your device. There's no MIRAGE server, no account, and secrets are never stored. Q&A cheat sheet

QuestionAnswer
Does my data go to your server?No. Detection runs on the device (browser, Mac app, terminal). There is no MIRAGE server. Only the protected text goes to the AI.
How does it detect?Layers: text clean-up (hidden characters, look-alike letters, Indian-script digits) → patterns with checksums (Aadhaar Verhoeff, card Luhn, PAN format) → entropy for random-looking keys → context words ("PAN", "DOB", "my name is") → risk score.
How accurate is it?On our 181-prompt test set: precision 1.000, recall 0.996, F1 0.998, 0 false alarms on 28 clean look-alikes. Be honest: we wrote the test set ourselves; a blind test by others is next.
How fast?0.05 ms per prompt on average for detection. On the Mac the review opens about 0.15 s after you stop typing.
What does it miss?Names only with context ("my name is …"); a PAN split with spaces (e.g. "BNZPM 2501 K"); non-English text. Details it misses are sent as typed. That's why the review shows exactly what will be hidden.
Is the desktop app a keylogger?No. It reads only the message box of ChatGPT and Claude, only while they're in front. It watches only Return and clicks on Send, never records the screen and never logs text (its log has reason codes and timings only).
Where are the real values kept?Encrypted on the device (AES-GCM) for 24 hours so replies can show them; secrets are never stored at all.
What about the reply?The extension checks the AI's reply and shows the real values on hover, on your device only. The CLI's unmask does the same for text.
Which platforms?Extension: ChatGPT, Gemini, Claude, Copilot, Perplexity (Chrome, Edge, Firefox). Desktop: ChatGPT and Claude apps on Mac; Windows is a beta. CLI: Windows, macOS, Linux.

If something goes wrong on stage

ProblemDo this
No review on chatgpt.comCheck the toolbar shield says Protection on; reload the ChatGPT tab (Cmd/Ctrl+R) and try again.
No badge or review in the ChatGPT appMenu bar → MIRAGE → check ChatGPT shows Protected. Quit and reopen MIRAGE. Fallback: use Private Compose (⌥⌘M).
Wi-Fi is downSwitch to the hotspot. The CLI steps C1–C5 work offline; skip C6.
ChatGPT is slow to answerDon't wait for the reply: the point is what was sent, which is visible at once in the chat.
mirage chat claude errorsSkip C6 and show C4 (unmask) instead; it tells the same story offline.

MIRAGE · Tech Stack

What to say when the judges ask "What's your tech stack?"

Say this (30 seconds)

"MIRAGE is one detection engine in TypeScript, and we run the same engine in three products. The browser extension is built with WXT and React on Manifest V3. The desktop companion is native: Swift and SwiftUI on Mac, using Apple's Accessibility API to read the ChatGPT app's message box, and C# .NET on Windows with UI Automation. Both run our engine inside a built-in JavaScript engine. The CLI is Node.js for developers. Detection is ours: checksums like Verhoeff for Aadhaar and Luhn for cards, entropy for API keys, and context rules, which give a risk score from 0 to 100. Real values are stored AES-GCM encrypted on the device for 24 hours. There is no server: nothing leaves the device except the protected prompt."

If they ask more

QuestionAnswer
Why not use an AI model to detect?Speed and privacy. Rules with checksums run in 0.05 ms on the device, need no internet, and every result can be explained ("Why 100?"). A model would need a server or a big download.
How do you run one engine on Mac, Windows and the browser?The engine is plain TypeScript bundled into one JavaScript file. The browser runs it directly, the Mac runs it in JavaScriptCore, Windows in Jint, and the CLI in Node.
How does the desktop app see ChatGPT's text?Through the operating system's accessibility interface (the same one screen readers use), and only for the message box of ChatGPT and Claude. No keylogger, no screen recording.
Is there a backend?No. No server, no account, no database. Only the protected prompt goes to the AI.
What's encrypted?The map from placeholder to real value (e.g. «PAN_1» → the real PAN), AES-GCM, on the device, deleted after 24 hours. Secrets like API keys are never stored at all.

One last step in your browser

MIRAGE is installed on this computer. Chrome and Edge run extensions from outside their stores only after you allow it once.

  1. Open the extensions pageType chrome://extensions in Chrome's address bar (or edge://extensions in Edge) and press Enter.
  2. Turn on Developer modeThe switch is at the top right in Chrome, and on the left in Edge.
  3. Click “Load unpacked” and choose this folder
    %LOCALAPPDATA%\MIRAGE\chrome-extension\extensionCopied
    Paste it into the folder picker's address bar, then click “Select Folder”.
  4. Pin MIRAGEOpen the puzzle-piece menu next to the address bar and pin MIRAGE, so you can see it is on. Then open ChatGPT or Gemini and try it.
Updating: run the newer installer, then click the reload arrow on MIRAGE in the extensions page.
Uninstalling: click “Remove” on MIRAGE in the extensions page, then “Uninstall MIRAGE” in the Start menu.
Privacy: every check runs in your browser. MIRAGE has no server and sends nothing anywhere.
